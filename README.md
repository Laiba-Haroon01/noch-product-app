# NOCH — Online Fashion Retail Platform

NOCH is a JavaFX-based e-commerce application developed as a first-year Computer Science project at Brunel University London.

The project was designed as an online fashion retail platform with separate functionality for customers and staff. I served as **Team Lead** and was responsible for designing and developing the complete **Products Module**, as well as integrating six team modules into the final application.

## 👩‍💻 My Role

**Team Lead & Products Module Developer**

My responsibilities included:

- Leading and coordinating the project team
- Designing the Products Module before development
- Creating interface prototypes in Figma
- Producing requirements and supporting design documentation
- Developing the customer-facing shop
- Developing the staff product management dashboard
- Designing and working with the SQLite database
- Integrating multiple team modules into one application
- Creating and delivering the final project presentation

## ✨ Key Features

### Customer Shop

The customer-facing side of the application allows users to:

- Browse available products
- Filter products
- View product information and images
- Use an image carousel
- Add products to favourites
- Add and remove products from a shopping basket
- View a live basket total
- Complete the checkout process

### Staff Admin Dashboard

The staff dashboard provides functionality to:

- Create products
- View product information
- Update existing products
- Delete products
- Search products in real time
- Filter product records
- Sort product data
- Manage product information stored in the database

## 📚 What I Learned

This project gave me experience with the wider software development process rather than only writing code.

Technically, I strengthened my understanding of Java, JavaFX, object-oriented programming, relational databases and connecting an application to SQLite using JDBC.

Building both the customer shop and staff dashboard also helped me understand how the same underlying data can be presented differently depending on the needs of the user.

Working with CRUD functionality, search, filtering, sorting, favourites, baskets and checkout functionality gave me experience developing features that interact with each other rather than working as isolated pieces of code.

I also gained a better understanding of the importance of planning before development. Creating Figma prototypes, database structures, UML diagrams and flowcharts helped me see how good preparation can make implementation more structured.

As Team Lead, I learned that successfully delivering a software project involves more than technical ability. Communication, task coordination, integration and understanding how each person's work contributes to the final product are equally important.

Presenting the completed application also improved my ability to explain a technical project clearly to an audience.
